Setup

입금 알림을 받기 전 먼저 확인할 세팅

계이득은 은행 앱 알림이 휴대폰에서 PC로 전달되어야 작동합니다. PC의 Phone Link, 휴대폰의 알림 접근 권한, 은행 앱 입금 알림을 모두 켜 둔 상태에서 사용합니다.

PC

Windows 휴대폰과 연결 준비

  1. Windows 휴대폰과 연결PC에서 휴대폰과 연결(Phone Link)을 실행하고 휴대폰을 연결합니다.
  2. 알림 허용Phone Link에서 휴대폰 알림이 PC로 표시되도록 알림 허용을 켭니다.
  3. 은행 앱 알림KB스타뱅킹, 토스, 케이뱅크 등 사용하는 은행 앱의 입금 알림을 켭니다.
  4. 리스너 유지계이득 실행 중 리스너를 끄면 안 됩니다. 리스너가 꺼지면 PC로 온 입금 알림을 읽을 수 없습니다.
