벽지는 저장, 배치, OBS 연결 순서로 사용합니다

최신 EXE 화면을 기준으로 벽지를 어디에서 만들고, 어디에서 OBS에 연결하는지 확인하세요.

저장된 벽지

후원으로 생성된 벽지를 슬롯에 배치합니다

이미지나 영상이 있는 시그니처를 저장해두고, 방송 상황에 맞게 그리드 슬롯에 올리거나 내립니다.

  • 5x5, 7x7 등 표시 슬롯 구성을 선택합니다.
  • 후원자 이름과 금액 기준으로 벽지 목록을 빠르게 찾습니다.
  • 선택한 벽지를 OBS 화면에 고정 표시하거나 전체 내림 처리합니다.
방송 중 자동 반영

시그니처 후원과 벽지 표시를 같은 흐름으로 제어합니다

방송 중에는 메인 컨트롤러에서 자동 벽지를 켜두고, 테스트 후원으로 실제 표시 흐름을 확인할 수 있습니다.

  • 수기 테스트로 시그니처와 벽지를 동시에 확인합니다.
  • 자동 벽지 체크 상태로 후원 발생 시 저장/표시 흐름을 연결합니다.
  • 선택 벽지, 스킵, 비우기 버튼으로 방송 중 상태를 정리합니다.
OBS 브라우저 소스

벽지 오버레이 주소를 복사해서 OBS에 추가합니다

오버레이 제어에서 벽지 주소를 복사하고 OBS 브라우저 소스에 넣으면 투명 배경 위에 벽지만 표시됩니다.

  • 벽지 오버레이 주소를 복사해 OBS 소스로 추가합니다.
  • 후원 알림과 벽지를 별도 소스로 분리해 겹침을 줄입니다.
  • 방송 중 전체 올리기/내리기로 화면 상태를 제어합니다.

배경을 가득 채우는 후원 연동 연출

단순 팝업 알림을 넘어, 방송 공간 전체의 비주얼과 조명을 후원 상태에 반응하도록 동기화합니다.

Feature 01 실시간 배경 이펙트 스택

후원이 발생하면 벽지 이미지 위에 실시간으로 입자 이펙트가 축적되거나 배경 조명이 화려하게 전환됩니다.

Feature 02 투명도 및 알파채널 제어

게임 플레이 화면이나 웹서핑 레이아웃 뒤에 은은하게 투영될 수 있도록 투명도와 합성 모드를 세밀하게 조절합니다.

Feature 03 커스텀 CSS 인젝션

개발자나 디자이너를 위해 직접 레이아웃 스타일 코드를 주입하여 고유 브랜드에 맞는 배경을 디자인할 수 있습니다.

Feature 04 대기/진행 상태 연동

특정 시간 동안 후원이 없으면 차분한 유휴(Idle) 대기 영상으로, 입금 발생 시 축제 모드로 스마트 스위칭합니다.

방송 벽지 오버레이 연출 파이프라인

방송 지연 없이 초경량으로 벽지 오버레이를 렌더링하는 핵심 흐름입니다.

  1. 1 웹 배경 및 동영상 소스 지정

    대시보드에서 방송 대기 배경용 웹 그래픽 주소나 비디오 소스를 등록합니다.

  2. 2 OBS 크로마키/알파 합성

    배경 알파채널을 투명으로 설정하여 게임이나 메인 캠 화면의 뒤편 레이어에 얹어 배치합니다.

  3. 3 후원 발생 시 인터랙티브 반응

    은행 입금 감지 즉시 전체 벽지의 패턴, 파티클, 글리치 애니메이션 등이 트리거되어 연출 효과를 극대화합니다.
