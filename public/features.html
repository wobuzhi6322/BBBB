Features Overview

방송에 뜨는 장면부터 확인하세요

계좌 후원이 들어왔을 때 OBS 화면에 어떤 알림, 랭킹, 벽지, 참여형 오버레이가 뜨는지 고객이 보는 순서대로 정리했습니다.

Feature Categories

방송 상황별 기능 카테고리

어떤 화면을 OBS에 넣어야 하는지 먼저 고를 수 있도록, 방송자가 실제로 쓰는 목적별로 기능을 묶었습니다.

01 후원 알림

계좌 입금 알림을 시그니처, 이미지, 영상, 음악으로 출력하는 핵심 OBS 화면입니다.

 02 방송 배경

벽지, 9:16 프레임, 방송 테두리처럼 화면 분위기를 유지하는 장식형 오버레이입니다.

 03 수동 카운터

흡/금, 먹어/먹지마처럼 방송자가 버튼으로 바로 조작하는 카운트 위젯입니다.

 04 랭킹 보드

후원 랭킹, 시트 랭킹, 통합 랭킹을 세로/가로형으로 방송 화면에 표시합니다.

 05 참여형 게임

태그 대결, 채팅 레이스, 라이브 픽처럼 시청자 참여를 만드는 방송용 이벤트 기능입니다.

실제 프로그램 화면으로 기능을 확인하세요

오른쪽 설명은 최신 실행 파일의 관리자 화면을 기준으로 정리했습니다. 왼쪽 기능을 누르면 해당 장면과 사용 목적이 바뀝니다.

방송 중 빠른 조작

후원 테스트, 카운터, 벽지, 랭킹을 한 화면에서 제어

방송 중에는 스크롤을 길게 내리지 않고 수기 테스트와 주요 오버레이 상태를 바로 만지는 것이 중요합니다.

  • 이름과 금액을 넣어 시그니처/벽지를 즉시 테스트합니다.
  • 흡연/금연, 먹어/먹지마 카운터를 버튼으로 빠르게 반영합니다.
  • 자동 벽지와 후원 랭킹을 같은 화면에서 확인합니다.
금액별 리액션

금액, 랭킹, 누적 조건별로 다른 시그니처를 준비

후원 금액에 맞춰 영상, 이미지, 음악, 텍스트 효과를 연결하고 OBS에 보내기 전 미리 확인합니다.

  • 기본 후원, 고액 후원, 오늘 최고 후원 같은 프리셋을 빠르게 만듭니다.
  • 흡연/금연 전용 시그니처를 별도 규칙으로 관리합니다.
  • 투명 배경 미리보기로 OBS 출력 전 화면을 점검합니다.
방송 화면 고정 연출

후원으로 생성된 이미지와 영상을 슬롯에 배치

시그니처가 끝난 뒤에도 방송 화면에 남길 벽지를 선택하고 그리드 단위로 정리합니다.

  • 5x5, 7x7 같은 슬롯 구성을 선택해 많은 벽지를 정리합니다.
  • 후원 이미지/영상을 표시 슬롯에 적용하거나 내릴 수 있습니다.
  • 자동 벽지 옵션으로 후원 발생 시 목록과 OBS를 연결합니다.
파일 관리

이미지, GIF, 음악, 영상을 업로드하고 규칙에 연결

방송에서 쓰는 리액션 자산을 한 곳에 모아두면 시그니처 편집 시간이 줄어듭니다.

  • 업로드된 파일을 검색하고 시그니처 규칙에 바로 적용합니다.
  • 영상은 OBS 재생에 맞춰 최적화된 파일로 관리합니다.
  • 요금제별 미디어 사용량을 확인할 수 있습니다.
OBS 연결

알림, 벽지, 랭킹, 방송 테두리 주소를 한 곳에서 복사

OBS 브라우저 소스에 넣을 주소와 방송 중 제어 옵션을 한 화면에서 관리합니다.

  • 후원 알림, 벽지, 랭킹 등 오버레이 주소를 복사합니다.
  • 현재 알림 스킵, 대기열 비우기 같은 방송 중 작업을 처리합니다.
  • 9:16 방송 테두리 효과와 TTS 옵션을 설정합니다.
후원자 관리

오늘, 이번 달, 전체 후원 데이터를 랭킹과 전용 시그니처로 연결

후원자 이름 기준으로 누적 금액을 관리하고 랭킹별 리액션을 따로 세팅합니다.

  • 이름별 후원 누적과 당일 랭킹을 확인합니다.
  • 상위 후원자 전용 시그니처와 색상 효과를 관리합니다.
  • 시트 랭킹과 계좌 후원 태그를 방송 화면에 반영합니다.

OBS Overlay Catalog

방송 화면에 실제로 뜨는 오버레이 장면

시청자에게 보이는 출력 장면을 기준으로 정리했습니다. 이름과 금액은 설명용 예시이며, 실제 방송에서는 프로그램 설정값을 따라갑니다.

Core 후원 알림 오버레이

계좌 후원 감지 후 시그니처 텍스트, 이미지, GIF, 영상, 음악을 큐 순서대로 출력하는 기본 방송 화면입니다.

Ambient 벽지 오버레이

시그니처 후 남기거나 수동으로 띄운 이미지/영상을 방송 배경처럼 고정 표시하는 투명 OBS 소스입니다.

Shorts Frame 9:16 방송 테두리 오버레이

시그니처가 발동할 때만 같이 켜지는 세로형 방송용 프레임입니다. 중앙 콘텐츠를 가리지 않고 외곽 라인만 연출합니다.

Manual 흡/금 오버레이

흡연/금연 카운트를 방송 화면에 작게 띄우는 수동 위젯입니다. 컨트롤러 버튼으로 횟수를 더하거나 초기화합니다.

Manual 먹어/먹지마 오버레이

먹방·미션 상황에서 “먹어/먹지마” 선택 카운트를 실시간으로 보여주는 수동 카운터 오버레이입니다.

Ranking 후원 랭킹 오버레이

프로그램 내부 후원 데이터를 기준으로 VIP 순위표를 세로 보드 형태로 출력합니다. 실제 방송에서 움직이는 랭킹 디자인을 영상으로 확인할 수 있습니다.

Ranking 후원 랭킹 가로형 오버레이

가로 배치 방송 화면이나 하단 띠 영역에 맞춰 후원 순위를 흘려 보여주는 랭킹 오버레이입니다.

Slot 후원 슬롯 오버레이

후원 순위 변동이나 특정 슬롯 변경을 짧게 강조해서 보여주는 보조 랭킹 연출입니다.

Sheets 시트 랭킹 오버레이

Google Sheets 공개 CSV의 1~15등 데이터를 읽어 방송용 랭킹 보드로 표시합니다.

Sheets 시트 랭킹 가로형 오버레이

시트 기반 랭킹을 쇼츠/가로 방송 하단에 넣기 좋게 가로형 카드 흐름으로 출력합니다.

Combined 통합 랭킹 오버레이

시트 VIP와 계좌 후원 랭킹을 한 화면에서 전환하거나 함께 보여주는 세로형 통합 랭킹입니다.

Combined 통합 랭킹 가로형 오버레이

시트 랭킹과 후원 랭킹을 가로형 띠 형태로 교차 출력해 방송 하단 정보 영역에 맞춥니다.

Battle 태그 대결 오버레이

후원 태그별 금액을 모아 게이지 대결로 보여주는 참여형 게임 오버레이입니다.

Control 라이브 픽 제어 화면

사진 슬롯, 참가자, 점수, 랜덤 배치를 관리하는 라이브 픽 운영용 화면입니다. OBS 출력과 함께 쓰는 관리자용 보조 화면입니다.
