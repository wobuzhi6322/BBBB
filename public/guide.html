계좌이체 한 번이면 3초 만에 방송 화면에 후원 메시지가 나타나요. 시청자 후원부터 스트리머 후원 페이지 만들기까지, 순서대로 정리했어요.

시청자 사용법

딱 4단계면 끝나요

채널을 열고, 메시지를 쓰고, 안내대로 이체하면 방송에 팡! 순서대로 따라와 보세요.

  1. 1

    채널 접속

    스트리머가 알려 준 주소(/@핸들)로 바로 들어가거나, 채널 탐색에서 채널명을 검색해 들어가요.

  2. 2

    닉네임·금액·메시지 작성

    방송에 표시될 닉네임과 후원 금액, 하고 싶은 말을 적어요. 로그인은 필요 없어요.

  3. 3

    안내된 입금자명으로 이체

    작성 완료 화면의 계좌번호로, 안내된 입금자명 코드를 한 글자도 바꾸지 말고 이체해요.

  4. 4

    방송에 표시

    입금이 확인되면 메시지가 방송 화면에 나타나요. 완료 화면의 진행 상태 확인 링크를 저장하면 창을 닫아도 다시 확인할 수 있어요.

🔑
입금자명 코드가 매칭 열쇠예요

예를 들어 계이득B7이라고 안내되면 — 닉네임 앞부분 + 영숫자 2자 조합이에요. 은행 앱에서 ‘보내는 분 이름’(받는 분 통장에 찍힐 내 이름)을 이 코드로 바꿔서 이체하면, 내 입금과 내 메시지가 자동으로 연결돼요.

시청자 사용법

시그니처로 더 특별하게

스트리머가 준비한 시그니처(후원 연출)를 고르면 금액이 자동으로 채워져요.

✨

시그니처를 누르면 정해진 금액이 자동으로 입력돼요. 영상 시그니처는 ▶ 미리보기로 어떤 연출인지 확인한 뒤 [이 시그니처로 후원하기]를 누르면 끝이에요.

시그니처 선택 → 금액 자동 입력 → ▶ 미리보기 → 후원하기

알아두면 좋아요

작은 규칙 여섯 가지

✍️

메시지는 200자까지

방송 화면에서 잘 읽히도록 후원 메시지는 200자 이내로 쓸 수 있어요.

🙋

닉네임은 20자까지

방송에 표시될 닉네임은 최대 20자까지 자유롭게 정할 수 있어요.

💰

최소 1,000원부터

후원은 1,000원부터 보낼 수 있어요. 채널마다 최소 금액이 다를 수 있어요(스트리머가 설정).

⏰

24시간 안에 입금해 주세요

메시지 작성 후 24시간이 지나면 예약이 만료돼요. 만료 후 입금은 메시지 없이 일반 후원으로만 재생됩니다.

🥇

먼저 작성한 메시지가 매칭돼요

같은 금액·같은 입금자명이 여러 건이면 먼저 작성한 메시지부터 순서대로 매칭돼요(first-match).

🔗

상태 링크를 저장해 두세요

완료 화면의 진행 상태 확인 링크를 저장하면 창을 닫아도 입금 확인·방송 표시까지 다시 확인할 수 있어요.

채널 찾기

채널·엔터로 찾아보기

주소를 몰라도 채널 탐색에서 직접 찾을 수 있어요.

🔎

채널 탐색에서 채널명이나 핸들로 검색해 후원 페이지로 바로 들어갈 수 있어요. 엔터(소속) 필터 칩과 채널에 붙은 엔터 뱃지로 같은 소속의 채널을 모아 볼 수도 있어요.

스트리머 사용법

내 후원 페이지, 네 단계면 열려요

로그인부터 방송 연동까지 순서대로 따라오면 몇 분이면 끝나요. 계좌이체로 후원금이 내 계좌에 바로 들어가 수수료는 0%예요.

  1. 1

    후원 페이지 만들기

    스트리머 탭으로 로그인(또는 스트리머로 가입)한 뒤 핸들을 정하면 내 후원 페이지 주소 /@핸들이 생겨요. 핸들은 30일에 한 번만 바꿀 수 있으니 신중히 정해 주세요. 이후 모든 설정은 스튜디오에서 관리해요.

  2. 2

    계이득 프로그램과 연동하기

    스튜디오 ‘프로그램 연동’ 탭에서 연결 코드를 발급받아, 계이득 프로그램 관리자의 ‘웹 후원 릴레이’ 카드에서 릴레이 서버 주소에 https://www.gaeideuk.com, 연결 코드에 발급받은 코드를 입력하면 ‘연결됨’으로 바뀌어요. 연동되면 은행 입금이 자동으로 웹 메시지와 매칭돼 방송 오버레이에 표시돼요. 매칭되지 않은 입금은 평소처럼 재생돼 기존 후원 흐름은 그대로예요.

  3. 3

    시그니처 메뉴 채우기

    스튜디오 설정에 팀코드(프로그램 공유 코드)를 입력하면 프로그램의 모든 시그니처가 웹 후원 메뉴에 자동으로 표시돼요. 비워 두면 릴레이로 동기화된 시그니처만 노출돼요.

  4. 4

    계좌·공개 설정

    은행·계좌번호·예금주를 등록하고 노출 방식(계좌번호 직접 노출 / 송금 링크만 보여주기)을 골라요. ‘채널 탐색에 노출’을 켜면 채널 탐색 목록에 등재돼 새로운 시청자가 찾아올 수 있어요(공개 시그니처가 1개 이상이거나 팀코드가 연동돼 있어야 목록에 떠요).

📎 스튜디오에서 페이지 주소 복사·QR 코드로 방송 설명란이나 오프라인 홍보에 바로 붙여 넣을 수 있어요.

FAQ

자주 묻는 질문

입금했는데 방송에 안 나와요

대부분 아래 셋 중 하나예요. 순서대로 확인해 보세요.

  • 시간창 — 메시지 작성 후 24시간 안에 입금했는지 확인해 주세요. 만료 후 입금은 일반 후원으로만 재생돼요.
  • 입금자명 — 안내된 입금자명 코드와 한 글자라도 다르면 매칭되지 않아요. 이체 내역의 표시 이름을 확인해 주세요.
  • 스트리머 프로그램 — 스트리머가 계이득 프로그램을 켜 두어야 방송에 표시돼요. 방송 중인지, 프로그램이 실행 중인지에 따라 표시 시점이 달라질 수 있어요.

완료 화면의 진행 상태 확인 링크에서 내 후원이 어느 단계인지 바로 볼 수 있어요.

계정 없이도 되나요?

네, 후원은 로그인 없이 바로 할 수 있어요. 로그인은 내가 보낸 후원 내역을 한곳에 보관하고 싶을 때만 쓰면 돼요.

익명으로 하고 싶어요

방송에 표시되는 닉네임은 자유롭게 정할 수 있어요. 다만 입금자명 코드는 내 입금과 메시지를 연결하는 열쇠라서, 은행 이체 시에는 안내된 입금자명을 그대로 써야 해요.

최소 후원 금액을 바꿀 수 있나요?

기본 최소 금액은 1,000원이에요. 스트리머는 스튜디오 설정에서 자기 채널의 최소 후원 금액을 조정할 수 있어요.

환불은 어떻게 하나요?

후원금은 계이득을 거치지 않고 스트리머 계좌로 직접 이체돼요. 그래서 환불도 해당 스트리머에게 직접 문의해 주셔야 해요.

핸들을 바꾸면 이전 주소는 어떻게 되나요?

핸들(내 주소 /@핸들)은 30일에 한 번 바꿀 수 있어요. 주소가 바뀌면 이전 주소로는 접속되지 않으니, 방송 설명란·SNS의 링크를 새 주소로 업데이트하고 이전 주소로 찾아온 시청자에게 새 주소를 안내해 주세요.

엔터(소속)는 어떻게 붙나요?

엔터(소속)는 운영 관리자가 배정해요. 소속이 생기면 채널에 엔터 뱃지가 붙고, 시청자는 채널 탐색의 엔터 필터로 같은 소속 채널을 모아 볼 수 있어요.

연동했는데 매칭이 안 돼요

아래 네 가지를 확인해 주세요.

  • 금액 — 입금 금액이 후원 금액과 정확히 일치해야 해요.
  • 입금자명 — ‘보내는 분 이름’이 안내된 입금자명 코드와 같아야 해요.
  • 시간창 — 메시지 작성 후 24시간 안에 입금해야 해요.
  • 프로그램 실행 — 계이득 프로그램이 실행 중이어야 릴레이가 입금을 감지해 방송에 표시해요.
충전·카드 결제는 언제 되나요?

충전(지갑)과 카드 결제는 지금 준비 중이에요. 준비되는 대로 공지로 알려 드릴게요.
